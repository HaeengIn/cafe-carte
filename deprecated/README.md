# Cafe Carte Unofficial Fan Website

## Introduction

This is repository of Unofficial Fan Website of **Cafe Carte**, 3D V-Tuber group of [TWILLIT STUDIO](https://cafe.naver.com/twillitstudio).

## Contribution

### Requirements

Please install following requirements to contribute.

- Python 3.12.0 (or upper, but recommend 3.12.0)
- uv (which is installed via pip)

If you have(or already) installed these requirements, follow below steps:

1. Clone repository and move to project folder
    ```bash
    git clone https://github.com/HaeengIn/cafe-carte.git && cd cafe-carte
    ```
2. Sync virtual environment and packages via uv
    ```bash
    uv sync --frozen
    ```
3. Code, commit, and make a pull request!
